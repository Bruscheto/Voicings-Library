# Piano samples

Splendid Grand Piano (Steinway), mezzo-forte layer: public domain samples released by Akai.
Converted to Opus and AAC by [smpldsnds](https://github.com/smpldsnds/sfzinstruments-splendid-grand-piano).

Regenerate with `pnpm run piano:samples`; the note list comes from `packages/keyboard/src/pianoSamples.ts`.
